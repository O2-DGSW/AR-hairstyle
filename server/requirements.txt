# heddy-v2 서버 런타임 의존성

# 무엇을 커버하는가
#   server/*.py 와 그 안에서 불러 쓰는 external/HairFastGAN 을 실행하는 데
#   필요한 파이썬 패키지. 각 줄은 실제 import 문을 추적해서 고른 **직접
#   의존성**이다. 전이 의존성(scikit-image, numba, tokenizers, matplotlib,
#   scikit-learn 등)은 일부러 적지 않았다. pip freeze 를 통째로 박아두면
#   패키지 하나 올릴 때마다 이 파일이 같이 썩고, 무엇이 진짜 필요한지
#   아무도 알 수 없게 된다.
#
# 무엇을 커버하지 않는가
#   **모델 가중치.** 리포에 없다. 따로 받아야 한다(README.md 참고).
#     - server/models/face_landmarker.task            (MediaPipe Tasks)
#     - server/models/selfie_multiclass_256x256.tflite (구 세그멘터 경로)
#     - external/HairFastGAN/pretrained_models/**      (약 7GB)
#   SegFormer(jonathandinu/face-parsing)만 예외로, 첫 실행 때 HF 허브에서
#   자동으로 내려받아 로컬 캐시에 넣는다. 리비전은 config.py 에 고정돼 있다.
#
# 설치
#   torch / torchvision 은 CUDA 휠(+cu124)이라 PyPI 기본 인덱스에 없다.
#   아래 --extra-index-url 지시자가 이 파일 안에 있으므로 보통은
#       python -m pip install -r requirements.txt
#   로 충분하다. 지시자를 무시하는 도구를 쓴다면 직접 넘겨라:
#       python -m pip install -r requirements.txt \
#           --extra-index-url https://download.pytorch.org/whl/cu124
#
# 검증 환경: Windows 11 / Python 3.12.0 / RTX 4070 SUPER / 드라이버 591.86
